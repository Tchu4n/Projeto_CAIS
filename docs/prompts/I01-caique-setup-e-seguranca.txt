### Checklist

```markdown
## CAIQUE Setup Inicial

### I01.1 — Google Gemini API

[ ] 1. Ir para https://console.cloud.google.com
[ ] 2. Criar novo projeto: "CAIS-CAIQUE"
[ ] 3. Ativar "Generative AI API"
[ ] 4. Ativar "Vertex AI API"
[ ] 5. Criar API Key (tipo: Restricted API Key)
[ ] 6. Adicionar ao .env.local:
    GEMINI_API_KEY=sua_key_aqui
    GEMINI_MODEL=gemini-2.0-flash
    GEMINI_TIMEOUT_MS=8000
[ ] 7. Testar com curl:
    curl -X POST https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=$GEMINI_API_KEY \
      -H "Content-Type: application/json" \
      -d '{"contents":[{"parts":[{"text":"Olá"}]}]}'
[ ] 8. Response deve conter {"candidates":[...]}

[ ] Função docsDaTrilhaVisiveis em lib/escopo.ts:

    - Output: docs ou []
    - Teste: empresa A não vê docs de empresa B

[ ] Testes de segurança em lib/carga.casos.ts:
    - [ ] T1: Admin vê todas as trilhas
```
