# CAIQUE — Guia de Troubleshooting

## Erros da API

### 401: Não autenticado
**Causa:** Sessão expirou ou não tem login

**Solução:**
1. Fazer login novamente
2. Verificar cookie de session (DevTools → Application → Cookies)
3. Se cookie expirou (> 30 dias), fazer logout + login

### 403: Sem permissão
**Causa:** Tentando acessar trilha de outra empresa

**Solução:**
1. Verificar companyId no contexto
2. Isolamento é por design, não pode contornar
3. Admin? Verificar se role="admin" na session

### 429: Rate limit
**Causa:** Muitas requisições ao Gemini API

**Solução:**
1. Aguardar 60 segundos
2. Retry automático? Não implementado em v1 (fazer em v2)
3. Aumentar limite no Google Cloud Console

### 500: Erro no servidor
**Causa:** Algo errado interno (logs não salvos, DB down, etc)

**Solução:**
1. Verificar logs do servidor: `tail -f logs/*.json`
2. Verificar pasta logs/ existe: `ls -la logs/`
3. Verificar GEMINI_API_KEY em production

## Erros do Frontend

### Chat não abre
1. F12 → Console: tem erro JavaScript?
2. Session ativa? `getSession()` retorna data?
3. CSS carregou? Inspecionar elemento (DevTools)

### Resposta vazia
1. Documentos da trilha existem? (admin check)
2. Gemini retornou vazio? (ver logs)

### Feedback não salva
1. POST /api/caique/feedback retorna 200?
2. logs/caique-*.json atualizado?

## Performance

### Chat demora muito (> 10s)
1. Rede lenta? (DevTools Network)
2. Pergunta muito complexa? Testar pergunta simples
3. Gemini sobrecarregado? Tentar mais tarde
4. Timeout pode aumentar para 15s (GEMINI_TIMEOUT_MS)

### Múltiplos usuários lentos
1. Rate limit Gemini? Aumentar quota
2. Banda DB? Verificar índices

## Dados

### Logs ocupam muito espaço
1. Arquivar logs antigos: `gzip logs/caique-2026-10-*.json`
2. Considerar limite de retenção (ex: 30 dias)

### Logs não salvando
1. Pasta logs/ tem permissão? `chmod 755 logs/`
2. Disco cheio? `df -h`
3. Error no console do servidor?

## Segurança

### API Key exposta acidentalmente
1. CRIAR NOVA chave no Google Cloud Console
2. Atualizar GEMINI_API_KEY em todas ambientes (dev, staging, prod)
3. Revogar key antiga (delete)
4. Verificar logs se alguém usou (audit)

### Isolamento quebrado
1. User A vê logs de User B?
2. Código em docsDaTrilhaVisiveis() está errado?
3. Query SQL parametrizada? `WHERE company_id=?` (não string concat)

## Monitoramento

### Métricas a acompanhar
- Response time: avg < 5s
- Error rate: < 5%
- Uptime: > 99.5%
- Feedback score: > 0 (mais 👍 que 👎)

### Alertas recomendados
- Response time > 10s (5 em linha)
- Error rate > 10%
- Uptime < 99%

### Ferramentas
- Logs: `logs/caique-*.json`
- Analytics: `/painel/caique-analytics`
- Sentry/Datadog: integrar em v2

## Rollback rápido

Se CAIQUE quebrar em prod:

1. Desabilitar widget (comentar `<ChatWidget />` em painel)
2. Deploy urgente
3. Investigar
4. Criar hotfix
5. Deploy hotfix
6. Re-habilitar

Tempo esperado: 5 minutos (com CD/CI automático)
